# Photo Poster Studio

A reusable Codex Skill for turning source photographs into separately art-directed posters through a catalog of named visual styles. Every input photo is processed independently unless a selected style explicitly requires otherwise.

## Current style

### `quiet-editorial-split`

A strict 3:4 vertical editorial poster:

- The top 50% preserves the source photograph with subtle magazine-grade color treatment.
- The bottom 50% reinterprets the same scene as a small, minimal handmade paper illustration.
- The palette uses no more than four dominant colors extracted from the photograph.
- Each uploaded photo produces its own poster?never a collage.
- The overall feeling is quiet, poetic, refined, spacious, and publication-led.

## Usage

Invoke `$photo-poster-studio`, upload one or more photographs, and request the `quiet-editorial-split` style. The Skill inspects and processes each photo separately, verifies the composition, and returns each poster as an independent image.

New visual styles can be added under `references/styles/` and registered in `SKILL.md` without changing the shared workflow.
